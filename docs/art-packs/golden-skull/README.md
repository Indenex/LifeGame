# Golden Skull Art packs (Max Heyder)

Paid art packs that Justin bought, for the art lanes to match against and to use in the game (D-232, D-234, D-235). See `docs/art-reference/` for the style guide.

**Licence.** Justin holds a commercial licence for these packs and says he has permission to host them in this public repo for now. The pack's own terms are in `LICENSE.txt`. Do not copy these files anywhere else, and do not share them outside the project. Justin may later move them out of the repo; use them through this path so that is easy.

| Folder | What's in it |
|---|---|
| `foliage/` | The 2D Isometric Foliage Pack. Painted cut-out sprites: forest grass tufts, ferns, clover, flowers, mushrooms, bushes, stumps, logs, stones, big leafy, needle and cypress trees, dead trees and bushes, reeds, water plants and bamboo, plus desert cacti and flowers. |
| `iso-starter/` | The 2D Isometric Starter Pack (2021 update). Painted tile textures: grass, dirt, stone, brick, wood, sand, snow, lava, water (with animation frames), path and shore overlays, cracks and grass patches, plus some foliage. |

## How the lanes use them

- **Environment:** the foliage sprites become alpha cards for the thick painted ground cover in the references: grass, ferns, clover, flowers and mushrooms. The tile textures guide terrain colour (grass, dirt, path, stone, shore).
- **Modeling:** variant D's painted materials match these tiles: wood planks, bark, stone, brick and thatch tones, rims and stroke style.
- **Atmosphere:** the palette and grade are checked against these.

Whatever goes into the game is copied into `client/` with a note that it comes from this pack.
