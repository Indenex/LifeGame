## Goal
KEYMAP says never to write a rebindable key into on-screen text. Three UX texts did anyway: the
Build menu's "B or Esc closes", the bag's "I or Esc closes" and the group invitation's "E joins".
After a rebind on the Controls page they named the wrong key. Each now reads the live binding:
`Controls.OrEsc(action)` gives "B or Esc", or "Esc" when the key is unbound, and is written each
time the panel opens. The invitation line uses `Controls.KeyFor("use")`.
