## Goal
Justin: "on character creation, people should get to choose their name." The first-join look picker gets a Name field at the top:
- pre-filled with your current name if it's a good one, otherwise a suggestion (the default "Wanderer-1234" isn't a valid name);
- a die button suggests a name that fits the world;
- Done stays off until the name is valid, and the reason shows under the field as you type.
SetName is hardened on the server (D-182), and /name keeps working for renames.

## Design
- **shared/Names.cs:** Normalize (control characters out, spaces collapsed, trimmed), Problem (the reason, or null), Key (lower case), Suggest (given names and homely surnames, avoiding taken ones).
  - Length is 2 to 20.
  - Allowed: letters (any Unicode letter), spaces, apostrophes (' and ’) and hyphens. A name starts and ends with a letter, with no two marks together.
  - Reserved: You, Admin, Administrator, Moderator, Mod, Server, System, Game, Everyone, Nobody, Someone, and every town office (Mayor, Deputy, Judge ...).
- **server/spacetimedb/Reducers.cs SetName:** normalizes, throws Problem as the error, and refuses a name another player has in any case ("That name is taken").
- **client/scripts/ui/NameField.cs:** the field, the die (a drawn die, since the default font has no emoji) and the reason line. It checks taken names from the public player table before asking.
- **LookPicker:**
  - The name row shows at first join only.
  - Done and Enter send SetName when the name changed, then SetLook.
  - OnSetName: if the server refuses the name the picker sent, it reopens with the reason under the field; other failures (/name in chat) become a note (Main sets Note).
- **Main:** no walking or jumping while a visible text box has focus, so typing a name doesn't move you.
- **tools/SocialTest:** the bot's name is letters only ("Tobin" plus six random letters). New checks: a taken name, an office title and digits are refused.
