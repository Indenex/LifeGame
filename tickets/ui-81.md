## Goal
Follows claims-32 (friends). Before, the friends list had no key and you could only add a friend
from the friends window. Now O (Justin picked O) opens and closes the friends list, rebindable on
the Controls page and listed in F1. The player menu (right click a player) gains "Add friend",
greyed with the reason when they already are your friend or you have the most friends allowed.
Resting the mouse on a friend shows a sage "Your friend" line. GroupView's distance wording now
comes from shared `Friends.HowFar`, so both windows say it the same way.
