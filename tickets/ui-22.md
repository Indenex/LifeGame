## Goal
Justin picked four player races (D-249/250/254): Bramble (chibi human), Kit (fox), Capling (mushroom sprite), Pebble (tortoise), on one shared 1.35 m base with swappable parts (Modeling). The look picker (ui-21, ui/LookPicker.cs) gains a row of race buttons at the top, then one row per option of the chosen race, built entirely from shared data, so a new race needs no UI code.

## Contract (proposed to Modeling 2026-10-17 03:40; they send the final shape when their base lands)
- player_look: append `Race` byte (default 0 = Bramble); the four existing bytes become generic option slots 0 to 3 whose meaning is per race.
- shared/Looks.cs: `Races` = RaceDef { Name, Options[] }; Option { Name, Names? (word buttons) or Swatches? ((r,g,b) tuples, round swatches) }; `Looks.Valid(race, a, b, c, d)`, `Looks.Default(playerId)`.
- Preview: PlayerModel.Build / SetLook with the race in the look.
