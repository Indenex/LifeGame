# Golden Skull ground tiles (prototype, env-27 option B+)

`ground_atlas.png` is cut from the Golden Skull Studios 2D Isometric Starter Pack (2021), which Justin bought (commercial licence, see `docs/art-packs/golden-skull/LICENSE.txt`): the top face of eight block tiles, unwarped from the isometric diamond to a 128 px square. Rows: grass (ISO_Tile_Dirt_01_Grass_01, ISO_Tile_Dirt_01_GrassPatch_01), dirt (ISO_Tile_Dirt_01, _02), sand (ISO_Tile_Sand_01, _03), stone (ISO_Tile_Stone_01, _02).
